# 经典与现代战斗模式

在同一个世界里切换经典或现代战斗规则，服务端会把当前模式同步给玩家。

Minecraft **1.21.1 / Fabric / Java 21**。源码版本 `1.1.3-mc1.21.1`，Mod ID：`combat_modes`。

按 **F7** 或输入 `/combatmenu` 打开菜单。也可以用 `/combatmode legacy`、`/combatmode modern` 切换；切换需要房主或管理员权限。

客户端和服务器都要安装。需要 GoldenAgeCombat 21.1.3、SwordBlockingMechanics 21.1.1 和 Puzzles Lib 21.1.60；它们的 JAR 不包含在仓库中。
